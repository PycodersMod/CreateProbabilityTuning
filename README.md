为 Create（机械动力）相关内容提供概率调校功能。

## 工程结构

可构建项目位于 [neoforge/1.21.1/](neoforge/1.21.1/)。仓库共享元数据保留在根目录。

## 构建

请进入目标目录并运行 Gradle Wrapper。

Windows PowerShell：

```powershell
cd neoforge/1.21.1
.\gradlew.bat clean build
```

Linux/macOS：

```sh
cd neoforge/1.21.1
./gradlew clean build
```
